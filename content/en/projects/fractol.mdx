# The project

Fract'ol is a graphical fractal explorer written in C with MiniLibX. It introduces complex numbers, iterative algorithms and graphics programming. Each pixel of the window maps to a point of the complex plane, and its colour depends on how quickly the associated sequence escapes.

---

# The fractals

- **Mandelbrot**: the classic set, with z0 = 0
- **Julia**: the same formula, with a complex constant given as an argument
- **Burning Ship**: a variant using absolute values at each iteration

---

# Features

- Zoom centred on the cursor with the mouse wheel
- Iteration depth that adapts while zooming
- Movement with the arrow keys and view reset
- Several colour palettes with smooth interpolation
- Double buffering with MiniLibX images
- Argument validation with a clear usage message

---

# What I take away from it

Computing with complex numbers, handling keyboard and mouse events, and optimising pixel-by-pixel rendering.
