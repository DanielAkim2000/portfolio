# The project

Libft is the first project of the 42 common core. The goal is to recreate my own C library by reimplementing libc functions, then extend it with utilities I reuse in every following project. The result is a static library, `libft.a`.

---

# What it contains

- **Characters**: tests (alphabetic, numeric, ASCII, printable) and upper / lower case conversion
- **Memory**: memset, bzero, memcpy, memmove, memchr, memcmp, calloc
- **Strings**: strlen, strlcpy, strlcat, strchr, strrchr, strncmp, strnstr, strdup, substr, strjoin, strtrim, split
- **Conversion and output**: atoi, itoa and functions that write to a file descriptor
- **Bonus**: linked list functions
- **Extras**: ft_printf, a reimplementation of printf, and get_next_line, which reads a file line by line

---

# What I take away from it

A library reused until the end of the curriculum: writing code that other projects (and my future self) will call demands rigour about memory management, edge cases and documentation.
