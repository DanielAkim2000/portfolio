# The project

The 42 C++ modules (00 to 09) are a progressive path to leave C behind and learn C++98: classes, inheritance, polymorphism, exceptions, templates, STL containers and algorithms. Each module is a repository with several exercises.

---

# The path

- **Module 00**: namespaces, classes, member functions, streams, initialisation lists, static and const. An interactive phone book and completing a bank account class
- **Module 01**: memory, pointers and references. Heap versus stack with a horde of zombies, file reading and writing, pointers to member functions
- **Module 02**: ad hoc polymorphism, operator overloading and the orthodox canonical form, with a fixed-point number class, up to a point-in-triangle test
- **Module 03**: inheritance, up to multiple and virtual inheritance (the diamond problem)
- **Module 04**: subtype polymorphism, deep copy, abstract classes and interfaces
- **Module 05**: exceptions, with bureaucrats, forms and a form factory
- **Module 06**: type conversions (casts), serialisation and identifying the real type of an object
- **Module 07**: function and class templates, with a generic array that checks its bounds
- **Module 08**: STL containers and iterators, and a stack that exposes its iterators
- **Module 09**: the STL in practice, with a Bitcoin price converter, a reverse Polish notation calculator and the Ford-Johnson sort compared across two containers

---

# What I take away from it

The principles of object-oriented programming in C++ (canonical form, polymorphism, RAII), sensible use of the STL, and the rigour of code that compiles without warnings under the C++98 standard.
